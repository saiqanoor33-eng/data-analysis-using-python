# Task 02 – Analyze Data Using Python

## Project Overview

This project analyzes a cleaned movie dataset using Python, Pandas, NumPy, and Matplotlib.

## Dataset

The dataset contains information about:

* Movie title
* Genres
* Release year
* Movie rating

## Analysis Performed

* Basic statistical analysis
* Highest and lowest rated movies
* Average movie rating
* Genre-wise rating comparison
* Release year analysis
* Relationship between release year and rating
* Correlation analysis

## Visualizations

1. Movie Rating Distribution
2. Release Year vs Movie Rating

## Key Findings

* The Dark Knight has the highest rating of 9.0.
* Avatar has the lowest rating of 7.8.
* The average movie rating is approximately 8.46.
* The analysis also examines the relationship between release year and movie rating.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
